# 2C Studio

A small studio that ships Solana products and remote MCP servers on Cloudflare Workers.

**We build for other teams:** your Solana web dApp turned into a Seeker app and taken through dApp Store review (from US$750), or an MCP server for your API so Claude, ChatGPT and Cursor can use it (from US$500).
→ [2cstudio.app/services](https://2cstudio.app/services)

## Open source

- [mcp-worker-template](https://github.com/2cstudiodev-web/mcp-worker-template): a small, production-shaped remote MCP server on Cloudflare Workers
- [seeker-dapp-store-checklist](https://github.com/2cstudiodev-web/seeker-dapp-store-checklist): turn a Solana web dApp into a Seeker app and get it through review
- [sealguard](https://github.com/2cstudiodev-web/sealguard): a free Solana wallet check-up with one-tap fixes (MIT)
- [steam-inventory-value-extension](https://github.com/2cstudiodev-web/steam-inventory-value-extension): source of our Steam Inventory Value browser extension
- [2c-emulator](https://github.com/2cstudiodev-web/2c-emulator): retro game emulator for the Solana Seeker (GPLv3)

## Live

- [SealGuard](https://guard.2cstudio.app): Solana wallet check-up, web and Android app on the Solana dApp Store
- [RipSeek](https://ripseek.2cstudio.app): odds and expected value for Collector Crypt card packs; its MCP server is rated A on Glama
- [Echoly](https://echoly.2cstudio.app): social post scheduler with an MCP connector in Claude's connector directory
- 6 apps on the Solana dApp Store
